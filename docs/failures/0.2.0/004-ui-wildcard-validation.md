# 004 — 高级页面通配域名校验断言失败

- 日期：2026-10-03。
- 分支：`feat/0.2.0-policy-profiles`。
- 阶段：实现高级 LuCI 页面后的 API 契约测试。
- 命令：`node tests/luci_contract.js`。
- 实际结果：`AssertionError: true != true`，新加入的无效域名用例 `*.` 被当作合法通配符接受。其余 Go race 测试通过；不能据此宣称整套测试通过。
- 原因：前端先去掉结尾点再判断 `*`，将无效的空通配后缀规范化为全匹配；后端规范化也需一致拒绝这一输入，避免意外扩大范围。
- 修复：前后端在规范化之前排除 `*.`，增加后端回归断言，重跑完整 LuCI 契约和 Go 测试。普通 `*`、`*.example.com`、根域尾点语义不变。
- 影响：仅开发测试失败，代码尚未部署至路由器；main 未改变。
